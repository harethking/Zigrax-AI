# Zigrax AI

كل نماذج الذكاء الاصطناعي بعقل واحد — عقل ذكي يحلّل كل طلب ويختار أنسب نموذج (Gemini, GPT, Claude, DeepSeek, Grok, Mistral, Llama, Perplexity…) حسب نوع المهمة والكلفة.

- تسجيل دخول برقم الهاتف مع رمز تأكيد SMS
- 3 باقات: مجاني (300 ألف توكن)، العادي (2.5 مليون — 9,000 د.ع)، برو (8 مليون — 19,000 د.ع)
- الحصة الشهرية مقسّمة على 4 أسابيع، والأسبوع على 7 أيام، واليوم على 4 فترات
- مفاتيح الـ API والحصص على السيرفر (Supabase Edge Functions)

الرابط: https://harethking.github.io/zigrax-ai/
